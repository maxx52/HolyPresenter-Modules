# HolyPresenter Modules

Официальный каталог и исходный код бесплатных модулей для HolyPresenter.

Сейчас в репозитории находится модуль `marketplace`. Он скачивает
`catalog.json`, проверяет SHA-256 и устанавливает выбранные модули в
пользовательскую папку HolyPresenter.

## Публикация модуля

1. Соберите JAR, содержащий дескриптор `META-INF/services/holypresenter.org.platform.api.module.HolyModule`.
2. Загрузите JAR в GitHub Release этого репозитория.
3. Добавьте запись в `catalog.json`.

Каждая запись должна содержать: идентификатор, название, версию, автора, описание, категорию, версию API, HTTPS-ссылку на JAR и контрольную сумму SHA-256.

Маркетплейс проверяет SHA-256 перед установкой и сохраняет модуль в
пользовательской папке. После установки требуется перезапуск программы.
